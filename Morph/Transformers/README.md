
# Transformer From Scratch

Having finished studying *Attention Is All You Need*, I'm now implementing the Transformer architecture from scratch to deepen my understanding of its underlying mechanics.

The goal is to translate the paper's concepts into working code, building each component step by step — from positional encoding and scaled dot-product attention to multi-head attention, feed-forward networks, and the complete encoder-decoder architecture.

**Approach:** Implement independently, test each component, and validate the results against the paper.

**Goal:** Build a solid, implementation-level understanding of the Transformer architecture without relying on prebuilt Transformer modules and to learn PyTorch.
